# Fabrizia Cárdenas — versão fiel ao layout de referência

Versão estática, mobile-first, feita para ser editada diretamente.

Tecnologias:
- HTML semântico
- CSS nativo
- JavaScript nativo
- @keyframes + transition + IntersectionObserver
- Google Fonts: Playfair Display + Montserrat

Não existe React, Express, banco de dados ou framework obrigatório.

## Estrutura

index.html
styles.css
script.js
assets/

## Imagens

As imagens estão separadas em `assets/`. Para trocar uma foto, basta substituir o arquivo mantendo o mesmo nome ou alterar o `src` no HTML.

## Importante

O telefone e endereço usados no layout vieram da informação disponível durante a montagem e devem ser confirmados pela profissional antes da publicação.

O bloco do Instagram está preparado como galeria visual/fallback. Se quiser um feed automático, pode ser conectado depois ao widget escolhido, sem mudar a estrutura principal.

## Publicação

Como é um site estático, pode ser enviado para hospedagem compartilhada que aceite HTML/CSS/JS. Não precisa manter um servidor Node rodando.
